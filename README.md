# Eletropostos Brasil – site e base de dados

Site público do app Android **Eletropostos Brasil** (desenvolvido e gerenciado pela [Spartan TI](https://spartanti.com.br)).

- `privacidade.html` – política de privacidade do app
- `stations.json` – base de eletropostos que o app baixa automaticamente (gerada por `data/merge.py`)
- `.github/workflows/atualizar-base.yml` – atualização automática semanal a partir do Open Charge Map e do OpenStreetMap
